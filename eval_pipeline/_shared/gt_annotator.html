导出的 human_annotations.jsonl 放到 gt 目录旁，执行（--reuse-runs 复用已有解析，不重跑）：
python -m eval_pipeline gt --input <原输入> \
    --piplup-orig <原版模块> --piplup-opt <优化版模块> \
    --human-annotations human_annotations.jsonl --reuse-runs --output <gt目录>
人工标注优先级高于一切自动裁决（adjudication='human', confidence=1.0），同步写入 final_gt.jsonl。
